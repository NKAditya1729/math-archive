# Lecture 10 — Equivalence of Product and Standard Topologies, Projections, and Homeomorphisms

## Where we are

In [Lecture 9]({{ site.baseurl }}/point-set-topology/lecture-09/), we established general properties of continuous maps: composition, restriction, and corestriction preserve continuity. We proved the universal property of the product topology—a map into a Cartesian product is continuous if and only if each coordinate component map is continuous—and used it to establish that sums, products, and quotients of continuous real-valued functions are continuous. Throughout earlier lectures, we repeatedly asserted that the standard topology on $\mathbb{R}^n$ coincides with the product topology on the $n$-fold Cartesian product $\mathbb{R} \times \dots \times \mathbb{R}$.

Here we open by supplying the rigorous proof that the standard topology $\tau_{\text{std}}$ and the product topology $\tau_{\text{prod}}$ on $\mathbb{R}^n$ are equal, utilizing the Comparison Lemma from Lecture 5. We then investigate a geometric application: central projection from the complement of a hyperplane onto a parallel target hyperplane. By setting up the line-parameter equation and computing the unique intersection point, we derive explicit coordinate formulas and prove continuity via the coordinate projection criterion. Restricting this map to the unit sphere punctured at the projection centre produces stereographic projection onto Euclidean space $\mathbb{R}^{n-1}$. Finally, we formally define a **homeomorphism**—the fundamental notion of isomorphism in topology—and prove its basic properties.

## Equivalence of standard and product topologies on $\mathbb{R}^n$

In [Lecture 6]({{ site.baseurl }}/point-set-topology/lecture-06/), we stated that on finite products of real lines, the product topology coincides with the metric topology given by open hypercubes. We now give the complete proof using the Comparison Lemma ([Lemma 5.1]({{ site.baseurl }}/point-set-topology/lecture-05/#lemma-5-1-the-comparison-lemma)).

### Proposition 10.1 (Equivalence of standard and product topologies on $\mathbb{R}^n$) {#proposition-10-1-equivalence-of-standard-and-product-topologies-on-rn}

{% capture prop101_content %}
On $\mathbb{R}^n = \prod_{i=1}^n \mathbb{R}$, let $\tau_1 = \tau_{\text{std}}$ denote the standard topology (generated by the basis $\mathcal{B}_1$ of open hypercubes/squares $S_\varepsilon(x)$), and let $\tau_2 = \tau_{\text{prod}}$ denote the product topology (where each factor $\mathbb{R}$ carries the standard topology $\tau_\mathbb{R}$).

Then:
$$\tau_1 = \tau_2.$$
{% endcapture %}
{% include block.html type="proposition" title="Proposition 10.1 (Equivalence of Standard and Product Topologies on $\mathbb{R}^n$)" content=prop101_content %}

{% capture prop101_proof %}
So recall that we had proved that if $X$ is a set with two topologies $\tau_1$ and $\tau_2$, and $\mathcal{B}_i$ is a basis for $\tau_i$, then if $\mathcal{B}_1 \subseteq \tau_2$ it implies $\tau_1 \subseteq \tau_2$ ([Lemma 5.1]({{ site.baseurl }}/point-set-topology/lecture-05/#lemma-5-1-the-comparison-lemma)). And we had used this result to prove that topologies are equal, so we will use this once again.

Let $\tau_1$ denote the standard topology on $\mathbb{R}^n$, and let $\tau_2$ denote the product topology.

**Step 1: We show that $\tau_1 \subseteq \tau_2$.**
A basis $\mathcal{B}_1$ for $\tau_1$ is given by sets of the form $S_\varepsilon(x)$, where $x = (x_1, \dots, x_n) \in \mathbb{R}^n$ and $\varepsilon > 0$.
Recall that this set $S_\varepsilon(x)$ consists of those points $y \in \mathbb{R}^n$ such that $|y_i - x_i| < \varepsilon$ for all $i$.
But this set is precisely equal to the Cartesian product:
$$S_\varepsilon(x) = \prod_{i=1}^n B_\varepsilon(x_i) = B_\varepsilon(x_1) \times B_\varepsilon(x_2) \times \dots \times B_\varepsilon(x_n),$$
where $B_\varepsilon(x_i) = (x_i - \varepsilon, x_i + \varepsilon)$.
Each $B_\varepsilon(x_i)$ is open in $\mathbb{R}$ under the standard topology, and therefore this product belongs to the basis $\mathcal{B}_2$ for the product topology ([Definition 6.1]({{ site.baseurl }}/point-set-topology/lecture-06/#definition-6-1-the-box-topology)).

So this implies that $\mathcal{B}_1$, which consists of these sets $S_\varepsilon(x)$, is contained in $\mathcal{B}_2$, which is contained in $\tau_2$:
$$\mathcal{B}_1 \subseteq \mathcal{B}_2 \subseteq \tau_2.$$
So this shows that $\tau_1$ is contained in $\tau_2$.

**Step 2: Now similarly, let us prove that $\tau_2$ is contained in $\tau_1$.**
So for that, next we will show that $\mathcal{B}_2$ is contained in $\tau_1$.
What does a typical element of $\mathcal{B}_2$ look like? An element of $\mathcal{B}_2$ looks like:
$$W = \prod_{i=1}^n U_i = U_1 \times U_2 \times \dots \times U_n,$$
where each $U_i$ is an open set in $\mathbb{R}$ ($U_i \in \tau_\mathbb{R}$).

Let $x = (x_1, \dots, x_n)$ be a point in this product $\prod_{i=1}^n U_i$.
Then for each $i$, there exists $\varepsilon_i > 0$ such that $B_{\varepsilon_i}(x_i)$ is completely contained in $U_i$.
So we choose $\varepsilon = \min \lbrace \varepsilon_1, \dots, \varepsilon_n \rbrace > 0$.
Then this implies that $B_\varepsilon(x_i) \subseteq U_i$ for all $i$, which implies that $\prod_{i=1}^n B_\varepsilon(x_i) \subseteq \prod_{i=1}^n U_i$.
Because this set is equal to $S_\varepsilon(x)$, we obtain:
$$S_\varepsilon(x) \subseteq \prod_{i=1}^n U_i = W.$$
For each $x \in W$, there is an $\varepsilon$ (depending on $x$) such that this open hypercube $S_\varepsilon(x)$ is completely contained inside $W$.
So taking the union over all $x$:
$$W = \bigcup_{x \in W} S_{\varepsilon(x)}(x).$$
And since arbitrary unions of open sets are open, this implies that $\prod_{i=1}^n U_i$ is open in the standard topology $\tau_1$.

So thus, this shows that the basis $\mathcal{B}_2$ is contained in $\tau_1$, which implies that $\tau_2$ is contained in $\tau_1$.

So this shows that the standard topology and the product topology on $\mathbb{R}^n$ agree. $\blacksquare$
{% endcapture %}

{% capture supp_finite_min %}
#### Why finiteness of the product is essential
In Step 2 of the proof, the radius $\varepsilon$ was chosen as the minimum of the positive radii:
$$\varepsilon = \min \lbrace \varepsilon_1, \dots, \varepsilon_n \rbrace.$$
A finite set of strictly positive numbers always has a strictly positive minimum. For an infinite product $\prod_{i \in I} U_i$, an infimum $\inf_{i \in I} \varepsilon_i$ can equal $0$, which is why the product topology requires all but finitely many factors to equal the whole space ($U_i = Y_i$). If one took products of arbitrary open sets without restriction, one would obtain the strictly finer **box topology** ([Lecture 6]({{ site.baseurl }}/point-set-topology/lecture-06/#definition-6-1-the-box-topology)).
{% endcapture %}

## Central projection from a hyperplane complement

We now investigate an explicit geometric map between Euclidean subspaces.

Let $n \ge 2$. Consider the following two parallel affine hyperplanes in $\mathbb{R}^n$:
- The target hyperplane:
  $$H = \lbrace (x_1, \dots, x_{n-1}, x_n) \in \mathbb{R}^n \;:\; x_n = 0 \rbrace.$$
- The parallel hyperplane:
  $$H' = \lbrace (x_1, \dots, x_{n-1}, x_n) \in \mathbb{R}^n \;:\; x_n = 1 \rbrace.$$
Both $H$ and $H'$ carry the subspace topology inherited from $\mathbb{R}^n$.

{% capture rem_hyp_iso %}
#### Canonical identification with $\mathbb{R}^{n-1}$
The hyperplane $H$ is canonically homeomorphic to $\mathbb{R}^{n-1}$ via the inclusion:
$$i : \mathbb{R}^{n-1} \hookrightarrow \mathbb{R}^n, \qquad i(x_1, \dots, x_{n-1}) = (x_1, \dots, x_{n-1}, 0).$$
Under this identification, the standard topology on $\mathbb{R}^{n-1}$ agrees exactly with the subspace topology on $H$ inherited from $\mathbb{R}^n$. A similar identification holds for $H'$.
{% endcapture %}
{% include block.html type="supplement" title="Canonical identification with $\mathbb{R}^{n-1}$" content=rem_hyp_iso %}

Fix the point on $H'$:
$$P = (0, \dots, 0, 1) \in H'.$$
We define a map from the complement $\mathbb{R}^n \setminus H'$ to the hyperplane $H$:
$$\phi : \mathbb{R}^n \setminus H' \longrightarrow H.$$

**Geometric description:**
Let $x \in \mathbb{R}^n \setminus H'$. Consider the straight line in $\mathbb{R}^n$ passing through $x$ and the fixed centre point $P$. Because $x \notin H'$, the last coordinate satisfies $x_n \ne 1$, so this line is not parallel to $H$. It meets the hyperplane $H$ at a unique point $Q$.
We define:
$$\phi(x) = Q.$$

   src="point-set-topology/lecture-10/hyperplane-central-projection.svg"
   caption="Central projection $\phi : \mathbb{R}^n \setminus H' \to H$. The line joining $P = (0, \dots, 0, 1) \in H'$ and $x \in \mathbb{R}^n \setminus H'$ intersects the target hyperplane $H$ at the unique point $Q = \phi(x)$."
   alt="Geometric diagram showing hyperplanes H and H prime with centre point P on H prime, a point x not on H prime, and the straight line through P and x meeting H at Q." %}

### Proposition 10.2 (Continuity of the central projection) {#proposition-10-2-continuity-of-the-central-projection}

{% capture prop102_content %}
Equip $\mathbb{R}^n \setminus H'$ and $H$ with the subspace topologies inherited from $\mathbb{R}^n$.
Then the central projection map
$$\phi : \mathbb{R}^n \setminus H' \longrightarrow H$$
is continuous.
{% endcapture %}
{% include block.html type="proposition" title="Proposition 10.2 (Continuity of the Central Projection)" content=prop102_content %}

{% capture prop102_proof %}
The idea is to first describe $\phi$ in terms of coordinates, and then see that each coordinate function is continuous.

**Reduction via corestriction:**
The image of $\phi$ lands in $H$, and $H$ has the subspace topology from $\mathbb{R}^n$.
Recall what we have proved: we can view $\phi$ as a map to $\mathbb{R}^n$, with the inclusion $i_H : H \hookrightarrow \mathbb{R}^n$.
Since $H$ is given the subspace topology, to show that $\phi$ is continuous, it is enough to view $\phi$ as a map from $\mathbb{R}^n \setminus H'$ to $\mathbb{R}^n$ and show that this map is continuous ([Lemma 9.3 (Corestriction to a Subspace)]({{ site.baseurl }}/point-set-topology/lecture-09/#lemma-9-3-corestriction-to-a-subspace)).
And that is exactly what we are going to do now.

**Derivation of the coordinate formula:**
Let $x = (x_1, \dots, x_n) \in \mathbb{R}^n \setminus H'$.
Every point on the line joining $x$ and $P = (0, \dots, 0, 1)$ is of the form:
$$L(t) = x + t(P - x) \qquad (t \in \mathbb{R}).$$
All points on this line are given by moving along the direction $P - x$ for different values of $t$. Coordinate by coordinate:
$$L(t) = \bigl((1 - t)x_1,\; (1 - t)x_2,\; \dots,\; (1 - t)x_{n-1},\; x_n + t(1 - x_n)\bigr).$$
We are looking for the point which lies on $H$, so we set the last coordinate to be zero:
$$x_n + t(1 - x_n) = 0 \iff t(x_n - 1) = x_n \iff t = \frac{x_n}{x_n - 1}.$$
And note that this $t_0 = \frac{x_n}{x_n - 1}$ is well defined, since $x_n \ne 1$ as $x \notin H'$.

Let us compute what $Q$ is going to be:
$$1 - t_0 = 1 - \frac{x_n}{x_n - 1} = -\frac{1}{x_n - 1}.$$
Therefore:
$$\phi(x) = \left( -\frac{x_1}{x_n - 1},\; -\frac{x_2}{x_n - 1},\; \dots,\; -\frac{x_{n-1}}{x_n - 1},\; 0 \right).$$

**Verification of continuity via coordinate components:**
So therefore, to show that $\phi$ is continuous, it is enough to show that each of the coordinate functions is continuous because on $\mathbb{R}^n$ the standard topology is the same as the product topology ([Proposition 10.1](#proposition-10-1-equivalence-of-standard-and-product-topologies-on-rn)).
And to check that $\phi$ is continuous in the product topology, we just have to check that each of the coordinate functions $\phi_i = p_i \circ \phi$ is continuous ([Proposition 9.4]({{ site.baseurl }}/point-set-topology/lecture-09/#proposition-9-4-product-criterion-for-continuity)). And that is exactly what we are going to do.

We check each coordinate function:
- For $1 \le i \le n-1$:
  $$\phi_i(x) = -\frac{x_i}{x_n - 1} = (-1) \cdot x_i \cdot \frac{1}{x_n - 1}.$$
  Here $x \mapsto x_i$ is the projection map, which is continuous ([Proposition 7.4]({{ site.baseurl }}/point-set-topology/lecture-07/#proposition-7-4-continuity-of-coordinate-projections)).
  The function $x_n - 1$ is continuous, and $x_n - 1$ does not vanish on $\mathbb{R}^n \setminus H'$.
  Therefore the reciprocal map $x \mapsto \frac{1}{x_n - 1}$ is continuous on $\mathbb{R}^n \setminus H'$ ([Proposition 9.6]({{ site.baseurl }}/point-set-topology/lecture-09/#proposition-9-6-continuity-of-the-quotient)).
  So the product of all these three functions is continuous ([Proposition 9.5]({{ site.baseurl }}/point-set-topology/lecture-09/#proposition-9-5-continuity-of-sum-and-product)).
  Thus $\phi_i$ is continuous for all $1 \le i \le n-1$.

- For $i = n$:
  The last coordinate function is just the constant function $\phi_n(x) = 0$, which is continuous.

So this implies that $\phi : \mathbb{R}^n \setminus H' \to \mathbb{R}^n$ is continuous.
And so also, $\phi : \mathbb{R}^n \setminus H' \to H$ is continuous.

So this completes the proof of the claim. $\blacksquare$
{% endcapture %}
{% include block.html type="proof" title="Proof of Proposition 10.2" content=prop102_proof %}

## Stereographic projection of the punctured sphere

Identifying $H$ directly with $\mathbb{R}^{n-1}$ by dropping the final vanishing coordinate, we view $\phi$ as a continuous map:
$$\phi : \mathbb{R}^n \setminus H' \longrightarrow \mathbb{R}^{n-1}, \qquad \phi(x_1, \dots, x_n) = \left(-\frac{x_1}{x_n - 1}, \dots, -\frac{x_{n-1}}{x_n - 1}\right).$$

Consider the unit $(n-1)$-sphere in $\mathbb{R}^n$:
$$S^{n-1} = \left\lbrace x \in \mathbb{R}^n \;:\; \sum_{i=1}^n x_i^2 = 1 \right\rbrace.$$
The centre point $P = (0, \dots, 0, 1)$ lies on $S^{n-1}$. Furthermore, the intersection of $S^{n-1}$ with the parallel hyperplane $H' = \lbrace x_n = 1\rbrace$ is:
$$\sum_{i=1}^{n-1} x_i^2 + 1^2 = 1 \implies \sum_{i=1}^{n-1} x_i^2 = 0 \implies x_1 = \dots = x_{n-1} = 0.$$
Thus $S^{n-1} \cap H' = \lbrace P \rbrace$.
Consequently:
$$S^{n-1} \cap (\mathbb{R}^n \setminus H') = S^{n-1} \setminus \lbrace P \rbrace.$$
The punctured sphere $S^{n-1} \setminus \lbrace P \rbrace$ is a subspace of $\mathbb{R}^n \setminus H'$.

By [Lemma 9.2 (Restriction to a Subspace)]({{ site.baseurl }}/point-set-topology/lecture-09/#lemma-9-2-restriction-to-a-subspace), restricting the continuous map $\phi$ to the subspace $S^{n-1} \setminus \lbrace P \rbrace$ yields a continuous map:
$$\phi|_{S^{n-1} \setminus \lbrace P \rbrace} : S^{n-1} \setminus \lbrace P \rbrace \longrightarrow \mathbb{R}^{n-1}.$$
This geometric restriction is classical **stereographic projection** from the north pole $P$.

## Homeomorphisms and topological equivalence

Stereographic projection turns out to possess a remarkable property: it is an invertible continuous map whose inverse is also continuous. This motivates the central structural definition of point-set topology.

### Definition 10.3 (Homeomorphism) {#definition-10-3-homeomorphism}

{% capture def103_content %}
Let $X$ and $Y$ be topological spaces. A map $f : X \to Y$ is called a **homeomorphism** if:
1. $f$ is a bijection of sets (injective and surjective);
2. $f$ is continuous; and
3. The inverse map $f^{-1} : Y \to X$ is continuous.

If there exists a homeomorphism $f : X \to Y$, we say that $X$ and $Y$ are **homeomorphic**, denoted:
$$X \cong Y.$$
{% endcapture %}
{% include block.html type="definition" title="Definition 10.3 (Homeomorphism)" content=def103_content %}

{% capture rem_homeo_meaning %}
#### Topological equivalence
A homeomorphism is an isomorphism in the category of topological spaces. It sets up a bijective correspondence between the points of $X$ and $Y$, and simultaneously a bijective correspondence between the open sets of $X$ and the open sets of $Y$:
$$U \in \tau_X \iff f(U) \in \tau_Y.$$
Two spaces that are homeomorphic possess identical topological properties.
{% endcapture %}

## Exercises

{% capture ex101_content %}
Prove that the stereographic projection map
$$\phi : S^{n-1} \setminus \lbrace P \rbrace \longrightarrow \mathbb{R}^{n-1}, \qquad \phi(x) = \left( -\frac{x_1}{x_n - 1}, \dots, -\frac{x_{n-1}}{x_n - 1} \right)$$
is a bijection of sets.
{% endcapture %}
{% capture ex101_sol %}
We prove injectivity and surjectivity by directly finding an inverse map $\psi : \mathbb{R}^{n-1} \to S^{n-1} \setminus \lbrace P \rbrace$.

Let $u = (u_1, \dots, u_{n-1}) \in \mathbb{R}^{n-1}$. We seek a point $x = (x_1, \dots, x_n) \in S^{n-1} \setminus \lbrace P \rbrace$ such that $\phi(x) = u$.
The condition $\phi(x) = u$ means:
$$u_i = \frac{x_i}{1 - x_n} \qquad (i = 1, \dots, n-1).$$
Thus $x_i = u_i(1 - x_n)$.
Summing the squares of the first $n-1$ coordinates:
$$\sum_{i=1}^{n-1} x_i^2 = (1 - x_n)^2 \sum_{i=1}^{n-1} u_i^2.$$
Let $\|u\|^2 = \sum_{i=1}^{n-1} u_i^2$.
Since $x \in S^{n-1}$, we have $\sum_{i=1}^{n-1} x_i^2 = 1 - x_n^2 = (1 - x_n)(1 + x_n)$.
Equating the two expressions:
$$(1 - x_n)(1 + x_n) = (1 - x_n)^2 \|u\|^2.$$
Since $x \ne P$, we have $x_n \ne 1$, so $1 - x_n \ne 0$. Dividing both sides by $1 - x_n$ gives:
$$1 + x_n = (1 - x_n) \|u\|^2 = \|u\|^2 - x_n \|u\|^2.$$
Rearranging terms:
$$x_n (1 + \|u\|^2) = \|u\|^2 - 1 \implies x_n = \frac{\|u\|^2 - 1}{\|u\|^2 + 1}.$$
We compute $1 - x_n$:
$$1 - x_n = 1 - \frac{\|u\|^2 - 1}{\|u\|^2 + 1} = \frac{(\|u\|^2 + 1) - (\|u\|^2 - 1)}{\|u\|^2 + 1} = \frac{2}{\|u\|^2 + 1}.$$
Substituting $1 - x_n$ back into $x_i = u_i (1 - x_n)$:
$$x_i = \frac{2 u_i}{\|u\|^2 + 1} \qquad (i = 1, \dots, n-1).$$
We define $\psi : \mathbb{R}^{n-1} \to \mathbb{R}^n$ by:
$$\psi(u) = \left( \frac{2 u_1}{\|u\|^2 + 1},\; \dots,\; \frac{2 u_{n-1}}{\|u\|^2 + 1},\; \frac{\|u\|^2 - 1}{\|u\|^2 + 1} \right).$$

We verify the properties:
1. **Image lies in $S^{n-1} \setminus \lbrace P \rbrace$:**
   $$\sum_{i=1}^{n-1} x_i^2 + x_n^2 = \frac{4 \sum u_i^2 + (\|u\|^2 - 1)^2}{(\|u\|^2 + 1)^2} = \frac{4\|u\|^2 + \|u\|^4 - 2\|u\|^2 + 1}{(\|u\|^2 + 1)^2} = \frac{(\|u\|^2 + 1)^2}{(\|u\|^2 + 1)^2} = 1.$$
   Moreover, $x_n = \frac{\|u\|^2 - 1}{\|u\|^2 + 1} < 1$ for all $u \in \mathbb{R}^{n-1}$, so $\psi(u) \ne P$.
2. **Left and right inverses:**
   By construction, $\phi(\psi(u)) = u$ for all $u \in \mathbb{R}^{n-1}$, and $\psi(\phi(x)) = x$ for all $x \in S^{n-1} \setminus \lbrace P \rbrace$.
Therefore $\phi$ is a bijection of sets, with two-sided inverse $\psi$. $\blacksquare$
{% endcapture %}
{% include block.html type="exercise" title="Exercise 10.1 (Bijectivity of Stereographic Projection)" content=ex101_content solution=ex101_sol %}

{% capture ex102_content %}
Let $\psi : \mathbb{R}^{n-1} \to S^{n-1} \setminus \lbrace P \rbrace$ be the inverse stereographic projection map constructed in Exercise 10.1.
Prove that $\psi$ is continuous, and conclude that the punctured sphere $S^{n-1} \setminus \lbrace P \rbrace$ is homeomorphic to $\mathbb{R}^{n-1}$.
{% endcapture %}
{% capture ex102_sol %}
By the hint in the lecture, the punctured sphere $S^{n-1} \setminus \lbrace P \rbrace$ inherits the subspace topology from $\mathbb{R}^n$.
By [Lemma 9.3 (Corestriction)]({{ site.baseurl }}/point-set-topology/lecture-09/#lemma-9-3-corestriction-to-a-subspace), $\psi$ is continuous into the subspace $S^{n-1} \setminus \lbrace P \rbrace$ if and only if the composite map into $\mathbb{R}^n$
$$i \circ \psi : \mathbb{R}^{n-1} \longrightarrow \mathbb{R}^n$$
is continuous.

By [Proposition 9.4 (Product Mapping Criterion)]({{ site.baseurl }}/point-set-topology/lecture-09/#proposition-9-4-product-criterion-for-continuity), $i \circ \psi$ is continuous if and only if each coordinate function $\psi_i : \mathbb{R}^{n-1} \to \mathbb{R}$ is continuous:
- For $1 \le i \le n-1$:
  $$\psi_i(u) = \frac{2 u_i}{\|u\|^2 + 1}.$$
  The numerator $u \mapsto 2 u_i$ is a scalar multiple of the coordinate projection, hence continuous.
  The denominator $u \mapsto \|u\|^2 + 1 = \sum_{j=1}^{n-1} u_j^2 + 1$ is a sum of products of coordinate projections and a constant, hence continuous by [Proposition 9.5]({{ site.baseurl }}/point-set-topology/lecture-09/#proposition-9-5-continuity-of-sum-and-product).
  Since $\|u\|^2 + 1 \ge 1 > 0$, the denominator never vanishes on $\mathbb{R}^{n-1}$.
  By [Proposition 9.6]({{ site.baseurl }}/point-set-topology/lecture-09/#proposition-9-6-continuity-of-the-quotient), the quotient $\psi_i$ is continuous.
- For $i = n$:
  $$\psi_n(u) = \frac{\|u\|^2 - 1}{\|u\|^2 + 1}.$$
  By the exact same reasoning, numerator and denominator are continuous and the denominator never vanishes, so $\psi_n$ is continuous.

Since all $n$ coordinate functions are continuous, $i \circ \psi : \mathbb{R}^{n-1} \to \mathbb{R}^n$ is continuous.
By corestriction, $\psi : \mathbb{R}^{n-1} \to S^{n-1} \setminus \lbrace P \rbrace$ is continuous.
Since $\phi$ and $\psi$ are continuous mutually inverse bijections, $\phi$ is a homeomorphism:
$$S^{n-1} \setminus \lbrace P \rbrace \cong \mathbb{R}^{n-1}. \qquad \blacksquare$$
{% endcapture %}

{% capture ex103_content %}
Let $X$ and $Y$ be topological spaces, and let $f : X \to Y$ be a bijective continuous map.
1. Show that $f$ is a homeomorphism if and only if for every open set $U \subseteq X$, the forward image $f(U)$ is open in $Y$.
2. Show that if $f : X \to Y$ is a homeomorphism, then its inverse $f^{-1} : Y \to X$ is also a homeomorphism.
{% endcapture %}
{% capture ex103_sol %}
1. Let $g = f^{-1} : Y \to X$ be the set-theoretic inverse of $f$.
   By [Definition 7.1]({{ site.baseurl }}/point-set-topology/lecture-07/#definition-7-1-continuous-map), $g$ is continuous if and only if for every open set $U \subseteq X$, the preimage $g^{-1}(U)$ is open in $Y$.
   Because $g = f^{-1}$, for any subset $U \subseteq X$ we have the set-theoretic identity:
   $$g^{-1}(U) = (f^{-1})^{-1}(U) = f(U).$$
   Therefore:
   $$g \text{ is continuous} \iff \forall U \in \tau_X,\; f(U) \in \tau_Y.$$
   Since $f$ is already continuous and bijective, $f$ is a homeomorphism if and only if $g$ is continuous, which is true if and only if $f(U)$ is open in $Y$ for every open set $U \in \tau_X$.
2. Suppose $f : X \to Y$ is a homeomorphism.
   By definition, $g = f^{-1} : Y \to X$ is a bijection, and $g$ is continuous.
   The inverse of $g$ is $(f^{-1})^{-1} = f$, which is given to be continuous.
   Thus $g$ satisfies all three conditions of Definition 10.3, so $g = f^{-1}$ is a homeomorphism from $Y$ to $X$. $\blacksquare$
{% endcapture %}
